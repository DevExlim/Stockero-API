# Changelog

## v1 beta

### 1.1 private developer access — 2026-08-29

- Added manually approved `stk_live_…` API keys.
- Added hashed-at-rest secrets, one-time reveal, expiration, usage metadata, scopes, and revocation.
- Enabled read-only key access for restocks, stores, and statistics.
- Added member request and administrator review pages.
- Added server-side, Node.js, and mobile architecture guides.
- Added the live OpenAPI document at `/api/v1/openapi`.

### 1.0 first-party beta

- Added paid-member browser authentication through Discord.
- Added nearby store and restock endpoints.
- Added website report submission with immediate Discord publication and retry handling.
- Added confirmation, low-stock, and three-vote sold-out behavior.
- Added moderator and administrator endpoints with staff history.
- Added consistent errors with request IDs.
- Added service health reporting under the Stockero API name.

Future changes should be added here with a date, affected endpoints, and any action client developers must take.
